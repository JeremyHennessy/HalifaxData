# A bounded explanation, not a new collection

The optional `#/capital-explanation` route explains one historical numerical movement for the **Municipality of the County of Annapolis**, not the Town of Annapolis Royal.

It reuses the existing three-depth presentation. The brief distinguishes derived opening book value from reported closing value; detail recomputes eight exact identities; original evidence exposes 25 source facts, two derived values, the graph, source locators and independently accepted receipt. An export includes the exact capital record and both reviews.

The immutable annotation and receipt are hash-pinned. Its target must match the accepted capital bundle, source document, municipality, type, year and record. Runtime equations use integer arithmetic and explicit input IDs, never generic sums. Unknown currency and scale remain unknown. An explained numerical movement does not establish disposal purpose, legitimacy, cash proceeds or transaction accuracy.

No collection count or original source bytes change. Missing or corrupt optional evidence disables only the explanation and links back to the independently loaded capital explorer. The existing 14 collections remain separate.

Local tests cover admission, changed identity/hash/value/equation inputs, unavailable annotation and no-count-increment. Hosted browser checks cover all three depths at 360/768/1440 pixels, JSON export, repeated navigation/Back and isolated failure. Hosted checks must pass before any claim of public completion.
