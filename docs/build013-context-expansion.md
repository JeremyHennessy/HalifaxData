## Community Grants — 2025/26

- staff recommendation: 63 awards / $480,430 across seven funding categories;
- Council-approved program total: 63 awards / $476,430 after a net $4,000 adjustment.

The seven category totals remain **staff-recommendation values before the Council adjustment**. Build 013 does not silently redistribute the $4,000 reduction across categories. Application controls are 120 received, 31 ineligible and 89 eligible. Category requests reconcile to $1,224,009.14.

Community Grants are municipal funding records, not procurement awards or vendor payments. Repeat receipt is not an anomaly by itself.

## CAO Contract Amendment Reporting — November 15, 2023

Build 013 records the complete public Attachment 1 table from this one report. Seven source table rows produce eight financial observations because the MacIntosh Depot row contains two distinct POs with separate original/amendment/updated values.

The report states that Private & Confidential amendment reports are excluded. Therefore this is **not** a complete contract-amendment ledger or denominator.

The aggregate table column labelled `Value of Amendment` is treated as the published cumulative amendment amount used to reach the published updated value. It must not be represented as the current change-order request without the underlying individual report.

One source arithmetic discrepancy is preserved rather than corrected:

- Slayter Street PO 2070887247: $56,763 original + $28,663 amendment = $85,426, while the source publishes an updated value of $85,246; source delta = -$180.

This is a source-data-quality flag, not evidence of improper spending.

## Investigation use

Only contract-amendment observations can enter the Build 013 investigation queue, using the current screen of either:

- published cumulative increase >= 50%; or
- published amendment value >= $250,000.

The score orders review. It is not a probability of corruption, fraud, waste or illegality. Community-grant, museum and rural-transit funding rows are context-only and do not generate anomaly leads.
