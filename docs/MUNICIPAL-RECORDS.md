# Historical municipal operating observations

The separately reviewed provincial dataset contains 555 municipality / type / fiscal-year observations, with 10,750 reported numeric values across 12,765 measure slots. Coverage is 2013–14 through 2023–24, not current spending. The original 139-source register remains a research inventory; this collection does not turn every reference into an integration.

The explorer preserves municipality type, original measure keys, exact decimal text, reported zero, missing values, source row identities and capture hashes. The Mahone Bay 2023–24 placeholder contains no reported measures and is never rendered as zero spending. Source revenue definitions changed from 2016–17.

Source display metadata uses CAD. The underlying unit/scaling and exact accounting policy remain unverified, so the app shows source values without currency symbols or cross-record totals. These are operating-fund reports, not comprehensive consolidated accounts or payments.

Publication requires the accepted exact-byte receipt and a strict field projection. Browser journeys must verify filters, expanded definitions, mobile layout and explicit unavailable states before release.
