# Trace a program, not an invented transaction

The transformed federal factual projection contains Nova Scotia rows only: 43 monthly tables, 86 payment dates and 358 program-column slots, including 268 numeric cells. Blanks remain nonnumeric. Territorial financing is not a Nova Scotia program. Health-transfer deductions and reimbursements remain separately inspectable; primary-column sums are not net health transfers.

CAD is an explicit contextual inference from the official Canadian program, not a literal currency code in the table. The records disclose government-to-government payments, not recipient accounting recognition, contractor spending or service delivery. The 2026–27 snapshot is partial-year and must not be annualized automatically.

Three independently reviewed 2025–26 program mappings connect exact provincial budget-table observations to complete federal source populations. The controlled key is program + Nova Scotia + fiscal year, not a shared source transaction identifier. The app reproduces each integer sum and scaled budget value without labeling the difference as loss or the numeric match as a cash-to-accrual reconciliation.

Only transformed numeric facts and attributed source identifiers are projected. Original tables, narrative, logos and federal wordmarks are not republished. The review is not a commercial redistribution licence for source material; expanded copying needs separate rights review.
