# A receipt-bound layer beside the research inventory

The original 139 guide entries and four original fiscal-document references are not rewritten when a collection becomes public. Their reviewed bytes remain intact. A separate generated coverage manifest binds each published collection to its data hash, accepted independent receipt, review date, explicit scope, count and count unit.

The source register derives bounded-publication status from those collection links, not from the workbook’s planning claims. Original inventory notes are disclosed only as **research inventory notes, not published findings**. The fact that an inventory row was faithfully transcribed does not verify every assertion it contains.

Collections, documents, source families, observations, cells and relationships are different units. Collections can overlap, and their counts must not be added into a grand total. Supporting institutional or government-decision evidence outside the original reference list remains accessible through collection-specific original source links; no fictitious inventory entry is invented.

A review date is not a measurement date or assurance date. Historical periods, partial years, bounded document coverage and source limitations remain explicit. No scheduled source-ingestion refresh is configured in this repository; the continuous-integration deployment workflow is not an ingestion schedule.
