# HRM Accounts Payable machine-readable records request

## Intended first step

Submit this first as a **routine/informal access request** to Halifax Regional Municipality Finance / Accounts Payable. If HRM advises that the records are not routinely available, reuse the same scope in a Part XX Municipal Government Act access request rather than broadening it.

## Request

I am requesting an existing machine-readable report or export of Halifax Regional Municipality accounts-payable / vendor-payment records for **April 1, 2024 through March 31, 2026**.

I am looking for an existing standard report, query output, spreadsheet or delimited export from HRM's financial system. I am **not** asking HRM to create new calculations, conduct an analysis, or provide copies of all invoice documents.

Where the fields exist in the source system and are releasable, please include:

- payment or accounting document ID;
- vendor ID, if releasable;
- vendor / payee name;
- invoice or source-document ID, if releasable;
- invoice date;
- entry or posting date;
- payment or clearing date;
- document / gross amount;
- paid or cleared amount, if stored separately;
- tax amount, if stored separately;
- currency;
- purchase-order number, where applicable;
- contract or tender reference, where available;
- business unit;
- cost centre / responsibility centre;
- general-ledger account or expense category;
- capital project code or internal-order code, where applicable;
- payment method category, if releasable;
- credit, reversal, void or cancellation indicator; and
- document / payment status.

Please also provide any existing data dictionary or code list needed to interpret the export, including the meaning of document statuses, reversal/void fields, organizational codes, project/internal-order codes and the relationship between invoice documents and payment/clearing documents.

Please exclude bank account numbers, routing/transit information, payment-card numbers, tax identifiers, personal home addresses, personal contact information and any other protected personal or security-sensitive information that is not necessary to understand the public-money transaction.

If this two-year period is considered too burdensome, I would accept the same fields for **April 1, 2025 through March 31, 2026** as a first-stage release, provided stable identifiers are retained so a later release can be appended without double counting.

If invoice/source-document identifiers cannot be released, I would accept the most granular releasable payment export containing vendor/payee, payment/clearing date, paid amount and the available organizational, account, project and procurement references.

Electronic delivery in Excel, CSV or another machine-readable tabular format is preferred.

## Scope boundary

This request is specifically for **accounts-payable / vendor-payment transaction records**. Procurement award reports, contract values, budget lines, quarterly financial summaries and audited aggregate financial statements would not satisfy the request because they do not establish that a vendor invoice was paid.

## Evidence supporting the request design

HRM's 2021 *Management of Accounts Payable Audit* describes structured invoice records in the financial system containing vendor number, invoice number, date and amount, and reports data analysis across 122,328 processed invoices. OIPC Review Report 24-06 later addressed HRM legal-service invoices and recommended disclosure of invoice bottom-line totals and records of arbitrator fees while allowing protected content to remain severed. The request above therefore asks for a narrowly scoped structured export and expressly excludes sensitive fields rather than requesting complete invoice images.
