# Ground-up watchdog architecture

This implementation is new. No old application code, build layers, routes or schemas are retained.

## Public evidence desk

The homepage starts with an investigative question and a source-backed case, not a wall of performance scores. Financial records and source coverage remain directly searchable. A case supports a brief, context/chronology and original-evidence depth with shareable URLs. No login is necessary for public evidence.

Native browser modules keep the first application small and inspectable. All source strings enter the DOM as text. HTTPS-only external links are checked. The release builder copies an explicit file allowlist for each independently reviewed collection, not a research directory. Unreviewed cases fail the publisher rather than merely disappearing behind a hidden route.

## Evidence layers

1. Source register: original 139 guide references plus separately counted primary documents. Registration is not acquisition.
2. Evidence records: precise source locators, review method, limits and binary hashes where actually retained. Null hashes remain null.
3. Financial facts: original decimal text, currency, multiplier, fiscal period, stock/flow type, stage, accounting basis and reporting perimeter.
4. Relationships: explicit evidence-backed IDs, never name/amount coincidence.
5. Investigations: question, calculation, source IDs, confirmed facts, alternatives, gaps, responses and next steps. Neutral publication review is distinct from consequential allegation review.
6. Publication: strictly reviewed neutral records only for this first public foundation. Private anomaly detections belong outside this repository and release bundle.

## First workflow

Compare the original and amended 2026–27 departmental-expense estimate using the same financial dimensions. Trace both values to their primary document tables. Show the exact 53,592 CAD-thousands difference, the published government explanation and the unvalidated approval/payment/delivery links. This is a documented plan revision, not a loss, cash payment or misconduct finding.

## Additional reviewed workflows

- On-demand full-snapshot tender search with bounded streaming, SHA-256 shard checks, newest-date ordering and no ambiguous monetary aggregation.
- Exact reviewed supplier labels joined only through source-row and observation identities from the same capture. No aliases or ownership inference.
- Historical municipality/type/year records with 23 source measures, preserving missingness and original definitions.
- A separately reviewed municipal reporting question with exact within-row arithmetic and separately attributed rounded provincial profiles. This does not authorize automatic publication of new cases.

## Verification

Model tests cover unsafe URLs, schema failures, incompatible financial comparisons, missing numeric values, publication gating, search, paging and deep links. Browser CI covers 360 / 768 / 1440 widths, all public routes, three case depths, query/empty search, JSON evidence export, Back navigation and unavailable-data handling. Hosted verification and visual screenshot inspection are required before describing a release as live or complete.
