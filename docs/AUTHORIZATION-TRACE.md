# Exact-record authorization evidence trail

`#/authorization-trace/<record ID>` is an investigative workbench, not a new published finding or source collection. The only supported stage is a recorded authorization from the admitted supplemental-appropriation snapshot. Other stages are explicitly **not linked here**, never absent or zero.

The model selects an exact order/clause/year and preserves its original amount and source semantics. It does not combine fiscal years, interpret source Column I, infer an elected vote, assume every appropriation becomes a contract, or label an expenditure improper. Statutory references remain source-attributed, not independently interpreted or assumed current.

Residents can expand one next-record checklist, inspect source dates/identifiers, open primary locators and export the source record plus review and the workbench's explicit unknowns. No information request is sent. Optional purpose wording is included only for its exact reviewed target; failure does not suppress independently verified authorization evidence.

Coverage remains 14 collections and 139 guide references. The prior budget comparison chain now says approval is not linked **to that comparison**. Audit coverage explains 19 main rows plus three organization rows for one shared recommendation, without changing counts or accepted source bytes.

Tests cover all 23 records, identity and snapshot rejection, purpose exclusion for other rows/years, deterministic export and malformed routes. Hosted browser tests cover two fiscal-year targets at all three widths, exact-record navigation/Back, unknown-target failure and optional-purpose failure. Publication waits for those hosted checks and actual screenshot review.
